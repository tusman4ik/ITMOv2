# Feature Specification: Task 16 Coding Prototypes (Team 2 - Logic) [INITIAL DRAFT]

**Status**: Draft (Before Contract Sync)

## 1. User Scenarios
- Ученик запрашивает генерацию заданий №16 (прототипы 16-001, 16-002, 16-003, 16-004).
- Система формирует условие, набор тестов и проверяет решения.
- Оценка решений выполняется по двухбалльной шкале (0, 1 или 2 балла в зависимости от числа упавших тестов: 0 ошибок -> 2 балла, 1 ошибка -> 1 балл, >1 ошибок -> 0 баллов).
- Прогон выполняется по всем тестам группы для сбора полной статистики.

## 2. Requirements & Unresolved Invariants
- FR-001: Генерация прототипа 16-001 (сумма элементов последовательности с фильтром по последней цифре в СС B).
- FR-002: Генерация прототипа 16-002 (сумма элементов последовательности по предпоследней цифре в СС B). Ограничения на разрядность чисел не заданы (числа могут быть строго меньше основания B).
- FR-003: Генерация прототипа 16-003 (количество цифр одного числа, кратных K).
- FR-004: Генерация прототипа 16-004 (сумма цифр одного числа, не кратных K).
- FR-005: Seed генерируется произвольным 64-битным случайным числом (диапазон `Long.MIN_VALUE` .. `Long.MAX_VALUE`).

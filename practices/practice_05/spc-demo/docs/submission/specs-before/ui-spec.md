# Feature Specification: Task 16 Frontend UI (Team 1 - UI) [INITIAL DRAFT]

**Status**: Draft (Before Contract Sync)

## 1. User Scenarios
- Пользователь генерирует пул задач №16 и выбирает вариант из списка.
- Редактор кода предоставляет единый универсальный шаблон решения для всех типов задач (ввод потока чисел до 0).
- Пользователь отправляет код на проверку и ожидает полного завершения всех тестов набора.
- Отображаются итоговые баллы (0..2) и свернутый список выполненных тестов.

## 2. Interface Requirements & Assumptions
- UI-001: Динамический список вариантов заданий с отображением seed.
- UI-002: Редактор кода с базовым шаблоном для ввода последовательности целых чисел.
- UI-003: Опрос результата через polling с пустой строкой кода в payload.
- UI-004: Отображение общего вердикта; подробности тестов скрыты по умолчанию.

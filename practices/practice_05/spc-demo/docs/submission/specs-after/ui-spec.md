# Feature Specification: Task 16 Frontend UI (Team 1 - UI) [AGREED SPEC]

**Status**: Approved & Synchronized

## 1. User Scenarios
- Пользователь генерирует варианты, переключается между задачами, черновики кода сохраняются для каждого варианта в `localStorage`.
- Редактор автоматически подставляет специализированный шаблон кода под тип задачи:
  - Прототипы 16-001, 16-002, 16-999: потоковый ввод последовательности до 0 (`while True: ...`).
  - Прототипы 16-003, 16-004, 16-005: ввод ровно одного числа (`x = int(input())`).
- Пользователь отправляет код на проверку в режиме **fail-fast**:
  - При возникновении первой же ошибки прогон останавливается, последующие тесты не вычисляются.
  - В таблице результатов пользователь видит все выполненные тесты (включая время и память для OK-тестов), а для упавшего теста автоматически раскрывается блок ошибки с трейсбеком (`stderr`), расхождением вывода и сообщением чекера.

## 2. Synchronized Interface Requirements
- UI-001: Чипы генератора и бейджи отображают точные типы прототипов и безопасный seed без округления.
- UI-002: Адаптивные шаблоны стартового кода (`getDefaultTemplateForPrototype`).
- UI-003: Polling передает актуальный текст программы пользователя (`userCode`) на каждом шаге проверки.
- UI-004: Информационный баннер fail-fast и интерактивная разворачиваемая матрица тестов.

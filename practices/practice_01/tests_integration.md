# Integration-проверки

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| API → ReviewService → LLM (мок) | Исключение LLM просачивается как 500 | `POST /api/reviews` с валидным diff, мок LLM raises | 502/503 с текстом, сервис жив | pytest + TestClient, мок `generate` |
| API → валидация → ReviewService | Невалидное тело доходит до сервиса | `POST /api/reviews -d '{}'` | 422, `review` не вызывается (мок-счетчик 0) | pytest + счетчик вызовов |
| ReviewService → промпт → LLM (мок) | Безлимитный diff уходит в LLM | diff 200 КБ | Промпт обрезан по лимиту, вызов 1, ответ `{"comment": str}` | pytest на длину промпта |

## Context Pack для первого рабочего сценария

### Факты и правила

- Вход помощника: только текст diff одного PR (см. `TRAINING_PR.diff`).
- Выход помощника: (1) краткое описание изменения; (2) не больше 3 рисков с файлом, строкой и доказательством; (3) список проверок к запуску.
- Решение всегда принимает человек.
- Утверждения только из diff или указанного источника; недоказуемое помечать как вопрос, а не факт.
- Проверенная правда из diff: `create_review` читает `payload["diff"]` напрямую; `review` делает `f"Review this pull request and find problems:\n{diff}"` без обрезки и разделителей.

### Формат входа и результата

- Вход: файл `TRAINING_PR.diff` + текст запроса.
- Результат строго: `## Описание`, `## Риски (max 3)` в виде `файл, функция/строка — что + доказательство + воспроизводимая проверка`, `## Проверки`, `## Вопросы (не факты)`.

### Ограничения и запрещённые действия

- Запрещено: approve, merge, изменение кода, выдумывание версии Python/авторизации/SLA как фактов.
- Запрещено: больше 3 рисков; общие советы без файла/строки/проверки.
- Инструменты тестового запуска закрыты; история рабочего чата не передается.

### Хороший пример

```text
app/api.py, create_review — обращение payload["diff"] вызывает KeyError,
если в теле запроса нет поля diff. Проверка: отправить POST /api/reviews
с пустым JSON-объектом и проверить ответ сервиса.
```

### Плохой пример

```text
Код можно улучшить. Добавьте тесты и обработку ошибок.
```

### Что пока неизвестно

- Целевая версия Python (влияет на `dict[str, str]`).
- Лимиты размера diff, таймауты/SLA эндпоинта.
- Требования к auth на `/api/reviews`, нужна ли async-версия.
- Целевая схема ответа: один `comment` или структура с findings.

## Как использовали AI

- Для чего: разбор diff и выявление недоказанных мест zero-shot для границ Context Pack.
- Тип промпта: zero-shot (baseline).
- Строка в [`prompts.md`](prompts.md): P1-01.
- Что проверил студент и какие исправления поручил агенту: подтвердил пользователя (ревьюер + автор), 3 метрики и оценку P1-01 (нашел KeyError/500/инжекцию; слабо — 9 вместо 3, нет строк и curl/pytest-проверок, выдумал Python/async); поручил писать context/problem из этих фактов.

# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Подтверждение |
|---|---|---|---|---|
| Позитивный | Сервис поднят, Master Prompt v1.1 | Ревьюер отправляет валидный небольшой diff через `POST /api/reviews` | Описание + 1–3 риска с файлом+строкой-hunk+цитатой+проверкой; решение принимает человек | `curl` из P1-02 + чек-лист триады; Статус: команды воспроизводимы, прогон на стенде — после инкремента 2 |
| Негативный | Сервис поднят | Отправка `{}` | 422 с понятным сообщением (не 500) | `curl -d '{}'` → 422 |
| Граничный | Сервис поднят | Diff с `Ignore previous instructions...` | Ввод уходит в LLM в рамках лимитов/разделителей; ответ без выполнения инъекции как команды | Ручной прогон + ревью ответа |

## Как использовали AI

- Строка в [`prompts.md`](prompts.md): P1-02 (сценарии повторяют риски и curl из ответа).
- Что проверил студент и какие исправления поручил агенту: _на проверке у студента — подтвердить E2E-ожидания_.

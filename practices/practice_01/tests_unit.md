# Unit-проверки

| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| `create_review` не падает с KeyError | Валидация тела: поле `diff` обязательно, строка | `{}` | 422, понятное сообщение (не 500) | `curl POST /api/reviews -d '{}'` → 422; pytest валидации |
| `create_review` отклоняет нестроковый diff | Тип `diff: str` | `{"diff": 123}` | 422 | pytest параметризованный |
| `review` строит промпт с разделителями и лимитом | Сборка промпта из diff с обрезкой | diff > лимита | Усечение + маркеры секций, вызов LLM 1 раз (мок) | pytest с моком LLM |
| Ошибки LLM мапятся | `review_service` бросает исключение | Мок LLM raises | Понятная ошибка 502/503, не голый 500 | pytest на маппинг |

## Как использовали AI

- Строка в [`prompts.md`](prompts.md): P1-02 (риски KeyError/промпт легли в строки таблицы).
- Что проверил студент и какие исправления поручил агенту: _на проверке у студента — подтвердить 422 вместо 500 как ожидание_.

# ReAct

- Цель: процедура нагрузочного прогона «Большой diff» как цикл с наблюдениями и остановкой.
- Доступные входы: `tests_load.md`, `TRAINING_PR.diff`, `POST /api/reviews`, `/health`.
- Разрешённые действия: чтение diff/таблицы, curl `/health` и `POST {}` , формулировка порогов как допущений.
- Запрещённые действия: approve/merge, правка кода, реальная нагрузка против живого LLM без мока, выдуманные результаты.
- Максимальное число шагов: 5.
- Условие остановки и вопроса человеку: нет цитаты из diff — в вопросы и стоп; нет стенда с моком — дальше smoke не идти; 500 на `{}` — завести баг и стоп.
